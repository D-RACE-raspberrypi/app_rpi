# Modèles utilisés

- `yolov5n_seg_h8l_mz.hef` et `yolov5seg.json` : paquet hailo-models installé sur le Pi, segmentation Hailo-8L.
- `osnet_x1_0.onnx` : réidentification CPU ; provenance dans osnet_x1_0.README.md.
- `yolov8s_h8l.hef` : ancien backend de détection, conservé pour compatibilité.

Empreintes dans SHA256SUMS. Les licences des modèles et de leurs sources Hailo/YOLO/OSNet continuent à s’appliquer.
