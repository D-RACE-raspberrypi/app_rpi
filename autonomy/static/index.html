0 : aucun malus · 100 : forte préférence pour les passages observés. Le malus est multiplié par la proportion inconnue. En marche avant, les zones inconnues ne bloquent plus les trajectoires ; elles ajoutent uniquement ce malus.
Points retirés par degré d’écart : 0 = aucune préférence angulaire ; 5 = attraction forte. Le bonus vaut 50 − pente × écart en degrés.
Multiplicateur : 0 = aucun malus de proximité ; 1 = réglage initial ; 5 = forte préférence pour un passage dégagé. Les collisions restent interdites.

Influence linéaire de X à Y entre 0 et 20 cm, puis zéro au-delà. Le multiplicateur obstacles ci-dessus s’applique à X et Y. Si plusieurs obstacles influencent une direction, le malus maximal est retenu. Le gabarit reste vérifié séparément.
